# Sources et attribution

Le code portable et les modèles de ce dépôt mettent en œuvre une architecture
de gouvernance demandée par le propriétaire. Ils n'incorporent pas les contenus
métier ou secrets des projets d'origine.

Les sources de skills et licences sont enregistrées dans `config/skills-lock.json`.
Les licences amont sont conservées lors du téléchargement. Graphify est utilisé
via son paquet officiel 0.8.13 sous licence MIT ; l'adaptateur est séparé et verrouille sa version.
Les capacités de plugins ne sont pas redistribuées. Voir `docs/SKILLS.md`.

# Portable Imrane engine for ProTrain

This reusable engine is part of the private ProTrain kit. Follow the repository root README and scripts/bootstrap.py for installation. It creates isolated governance, project memory, hooks, snapshots, routing and bounded retrieval using Python 3.11+.

The source engine retains its private collaboration LICENSE and NOTICE. Third-party components retain their own terms. This engine grant does not license ProTrain project data. See docs/SHARING.md and the root NOTICE.toolkit.md.

This edition combines the current generic runtime hardening/offline graph with the clean release initialization, isolated distribution and complete snapshot logic. The installer generates destination-specific hook commands, uses the current six Luna/Sol routes capped at high, and installs only the curated offline skills. It does not run the historical online skill catalogue or install dependencies.

The source script tests cover routing, offline graphs, runtime operations and managed-file protections. Bootstrap installation tests are recorded separately. Actual host trust, native hooks, model availability and worker delegation remain local client capabilities.

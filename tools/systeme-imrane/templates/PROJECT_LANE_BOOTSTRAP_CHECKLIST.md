# New lane acceptance checklist

- Unique id/path registered; no root business lane or overlapping scope leak.
- Own AGENTS.md, CLAUDE.md and narrowly mapped mission/stack/authority.
- Own four canonical memory files and a task-based context index.
- Codex/Claude hooks target shared portable runner, not one business project.
- Isolated ignored runtime/snapshots, secrets and Graphify output.
- Reviewed Graphify include/exclude paths; no raw media/generated directories.
- User-selected models/credentials; no default billing/provider escalation.
- Own Git repository where desired; no automatic deployment or commit.
- Actual build/test/QA commands documented and executed when applicable.
- Synthetic hook test confirms cwd routing, bounded context and secret exclusion.

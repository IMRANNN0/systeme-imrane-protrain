# Curated offline skills

This private edition installs 38 canonical skill entrypoints: 37 payload modules and one generated engine wrapper. See the repository root kit/skills-manifest.json for current provenance, exact file hashes and portable changes. Bootstrap creates an identical Claude mirror from this single canonical payload. No affiliate workflow or DP production suite is included.

Keep each upstream license/notice. Media-buying course adaptations have a separate course notice. Current video/static review methods and the work-management CLI/resources are bundled. Some source references remain in their original French; project French/Arabic content is preserved.

The engine historical config/skills-lock.json is an optional source catalogue, not this edition's installed census. Do not run its online --all installer to replace the curated offline library. External runtimes, services, browser tools, generation providers, plugins and personal authentication are separate, optional capabilities. Read the root docs/DEPENDENCIES.md and the chosen skill before executing helpers or downloads.

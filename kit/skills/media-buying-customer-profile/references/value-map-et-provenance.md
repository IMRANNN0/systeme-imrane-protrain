# Value Map — référence conservée et provenance

Lire cette référence pour utiliser un inventaire existant, préparer le passage depuis Customer Profile ou retrouver la provenance. Elle conserve le matériel Value Map fourni, désormais disponible dans le skill distinct [media-buying-value-map](../../media-buying-value-map/SKILL.md) ; ce n'est pas une consigne de produire automatiquement sa Value Map complète.

## Ordre et limites

Dans Value Creation, le cours distingue Customer Profile, Value Map et Feature-Benefit Laddering. Pour une création de zéro : Customer Profile puis Value Map. Pour un produit existant : inventaire Value Map/capacités réelles, segments candidats, puis profils. Sans inventaire, demander le minimum utile et conserver les segments comme hypothèses. Aucune méthode FBL n'a été fournie : ne pas la reconstruire à partir de son nom.

## Matériel Value Map fourni

| Partie | Contenu du cours |
| --- | --- |
| Products & Services | Produits/services physiques, intangibles, digitaux, financiers |
| Gain Creators | Fonctionnalités, améliorations de performance, expérience utilisateur améliorée |
| Pain Relievers | Optimisation des défauts, facilité d'utilisation, atténuation des risques |

Le cours propose une pertinence **Nice-to-have → Essential**, en correspondance avec Jobs/Pains/Gains prioritaires. Les capacités actuelles doivent être distinguées de celles seulement proposées. Un appariement logique est une hypothèse de proposition de valeur, pas une preuve de demande, de ventes ou de résultats.

### Exemple pédagogique Holistic Health

Le matériel illustre un programme en ligne, des séances individuelles, un plan de repas, une communauté, des cours enregistrés et du coaching hebdomadaire. Il cite des plans personnalisés, le suivi des progrès et un soutien quotidien comme possibilités de création de gains ; un plan simple et un suivi comme possibilités de soulagement ; garantie, essai et témoignages comme exemples possibles d'atténuation du risque perçu.

Ces éléments appartiennent à l'exemple du cours. Ils n'établissent aucune capacité réelle, politique de garantie/remboursement, disponibilité d'essai ou résultat santé pour un client. Ils ne constituent pas une promesse validée à reprendre dans une publicité. Vérifier existence, conditions et preuves pertinentes avant toute correspondance appliquée ; une proposition reste étiquetée comme telle. Customer Profile n'exécute ni campagne ni rédaction d'annonces, hooks ou landing page.

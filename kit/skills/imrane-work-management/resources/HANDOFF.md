# Sharing a reviewed lesson

Keep the original work record and evidence in its registered source lane. The four canonical memories remain authoritative. Review and sanitize the exact lesson, including client names, URLs, screenshots, identifying details, proprietary figures and credentials.

`lesson-export` writes only a selected approved lesson to a local scoped file. It sends nothing. Before moving that file to another lane, a shared library or an external service, apply the recipient workspace's `docs/governance/HANDOFF_POLICY.md`: record purpose, source, destination and authorized data classes, and obtain any required owner authorization. The method does not relax that policy.

A sanitization flag is an attestation, not proof. Inspect the exported text. Change a skill only through an explicit reviewed edit with provenance and relevant checks; no background learning or automatic client-data promotion is performed.

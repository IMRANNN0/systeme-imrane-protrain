## ProTrain portable workspace rules

This workspace contains only ProTrain business data. Governance remains separate from the project lane. Resolve the longest registered path. At the root with no selector and no default, use governance. Do not infer a business component. Shared skills belong only in .agents/skills; .claude/skills is the generated mirror.

### Work, routing and checkpoints

Use the shared imrane-work-management skill and docs/governance/work-management/START_HERE.md for substantial delivery or planning. Keep tiny answers direct. Before stopping substantive work, update the selected lane CURRENT.md checkpoint with stage, acceptance check, last verified evidence and one specific next action. Record durable decisions separately and save an explicit snapshot when native lifecycle hooks have not been verified. Snapshots preserve existing memory; they do not write its meaning.

The owner requested this isolated work system. .codex/automatic-routing.json enables the controller to classify substantive Codex tasks and delegate one bounded native worker using the six configured Luna/Sol model and effort pairs. Use tools/imrane-route.py with JSON stdin, a stable session id and opaque task id. Record started only after the native worker launches; record finished or failed after its result. Wait, review and synthesize. Workers never delegate. Report unavailable models/delegation and do not silently substitute. Hooks only supply context; they neither launch workers nor change the active model. Claude stays advisory. Model/account availability and actual native hook loading require local verification.

### Marketing copy and creative review

When editing an existing landing page, preserve its design system and scope changes to the request. Use clear CTA labels without decorative arrows. Write concrete, natural marketing sentences, avoiding generic formulas, semicolons and punctuation em dashes. Preserve quotations, proper names, times, URLs and code syntax. Headings do not end with a full stop. Use the humanizer skill for marketing copy review.

For video planning, editing, voice synchronization and creative QA, read .agents/skills/performance-video-editing/SKILL.md and references/production-review.md before work and before handoff. Inspect the actual export and distinguish measured checks from human audiovisual review.

For static advertising concepts, marketing images or reviews, read .agents/skills/static-ad-creative-system/SKILL.md and references/review-checklist.md before the concept and again against the exported image. Default messaging functions are HOOK, PROMISE and CTA; this does not prescribe fixed rows. Read the selected project's current brand evidence, supported claims and durable creative feedback. Preserve all approval and rejection states. Keep new client observations inside ProTrain; reusable skills contain generic methods only.

No workflow stage authorizes publishing, contacting people, spending, dependency installation, network indexing or permission changes. Review a corpus and its destination before any semantic indexing. The installer creates only a narrow five-file lane scope and never refreshes an index.

بيئة محلية للمونتاج والحركة بالكود، تجهزات نهار الثاني عشر من نونبر. المشروع الحالي فيه تجربة تقنية قصيرة بالعربية، والهوية النهائية لفيديوهات بروترين باقي كتتحدد بالتجربة والمراجعة.

## التشغيل

فـPowerShell، دخل للمجلد بهاد الأمر.

```powershell
Set-Location -LiteralPath '{{PROTRAIN_PROJECT_ROOT}}/04 — SaaS & EdTech/editing-system/video-studio'
```

باش تفتح المعاينة.

```powershell
npm run studio
```

باش تفحص الكود وإصدارات الحزم.

```powershell
npm run check
npm run versions
```

باش تعاود تصدّر تجربة التثبيت واللقطة ديالها.

```powershell
npm run render:check
npm run still:check
```

الأوامر كتستعمل ملفات المحرك مباشرة باش تخدم داخل مسار Windows اللي فيه علامة `&`.

## شنو كاين فالمشروع

- `src/Root.tsx` فيه إعدادات التجربة والنصوص اللي تتبدل من الواجهة.
- `src/InstallationCheck.tsx` فيه العربية والحركة والإخراج ديال الاختبار.
- `out/installation-check.mp4` فيه الاختبار الصامت من ثلاث ثواني.
- `out/installation-check.png` لقطة من وسط الاختبار.
- `package-lock.json` فيه الإصدارات الدقيقة وبصمات الحزم.

إعدادات الاختبار هي ألف وثمانين على ألف وتسعمائة وعشرين، وثلاثون صورة فالثانية. تبديل النص من واجهة المعاينة وحفظه فالمصدر تجرّب فعلياً. كاين فحص للكود وفحص لفك ترميز الفيديو. تجارب الصوت والقص والكلمات المكتوبة تزادت فالتدريب العملي المبين تحت؛ تزامن صوت الدارجة الحقيقي باقي ما تجرّبش.

## التدريب العملي — 12 نونبر 2026

كاينين جوج مشاريع إضافية قابلين للتعديل فالمعاينة:

- `PracticeComparison`: شرح عربي من 18 ثانية، جوج ملفات توضيحية، رسوم أصلية، مقارنة النقط والشعب، ثم مراجعة شروط التكوين. المؤثرات الصوتية مولّدة محلياً؛ ما فيهش تعليق صوتي.
- `PracticeCut`: مادة تقنية اصطناعية بصوت إنجليزي محلي، حذف أربع ثواني من الفراغات المضافة مع الحفاظ على الجمل الثلاث. الكلمات المكتوبة مأخوذة من نص معروف، بلا تفريغ آلي ولا ترجمة لغوية.

إعادة التحضير والتصدير والتحقق:

```powershell
npm run practice:prepare
npm run check
npm run practice:render
npm run practice:verify
```

يمكن تصدير تمرين واحد بالأمر `npm run practice:render -- cut` أو `npm run practice:render -- comparison`.
التصدير متتابع وبمتصفح واحد لتقليل الضغط. السكريبت كيستعمل مجلد مؤقت محلي، حيث المسار المؤقت ديال بيئة Codex يقدر يحتوي علامة تعطل Webpack.

التحضير كيحتاج Windows والصوت المحلي `Microsoft Zira Desktop`، مع Python وFFmpeg.
التحقق كيستعمل `numpy` و`Pillow` الموجودين محلياً. ما تزادت حتى تبعية جديدة لهاد التجربة.
حدود القص الحالية مثبتة على المادة التجريبية المحددة: إذا تبدّل النص أو الصوت، خاص تحديث حدود المصدر والكلمات المكتوبة ومدة المشروع حسب `public/practice/edit-plan.json` قبل التصدير.

النتائج داخل `out/`، وسجل القياسات واللقطات داخل `out/practice-qa/`.
القواعد المستخلصة وحدود اللي تجرّب كاينة فـ[سجل التدريب](../PRACTICE_LESSONS.md).
الألوان المستعملة تجريبية؛ هادو تمارين تقنية وماشي إعلانات نهائية مصادق عليها.

## المراجعة الثانية

`PracticeComparisonV2` هي المراجعة البصرية الجديدة للشرح العربي. الأولى باقية محفوظة. جوج بطاقات كيبقاو ظاهرين خلال السؤال والمقارنة، ثم كيتصغّرو ويرتبطو برسم شروط التكوين. الخط والأرقام تكبّرو، وكل ملف عندو لون ثابت، والنهاية فيها خطوة عملية.

```powershell
python scripts/prepare-v2.py
npm run check
npm run practice:render -- v2
python scripts/verify-v2.py
```

المصدر `src/PracticeComparisonV2.tsx`، النتيجة `out/practice-comparison-v2.mp4`، وفحص الصور فحجم الهاتف داخل `out/v2-qa/`. صور الفحص الاختيارية كتخرج بالأمر `node scripts/render-practice.mjs v2 stills`.
التصدير كيحتافظ بسجل داخل `.cache/` وكيعطي وقت إضافي لتحميل المشهد. فالجهاز اللي فيه ضغط على الذاكرة، يمكن توقيف المعاينة المحلية قبل التصدير ثم إعادة فتحها بالأمر `npm run studio`.
تفاصيل النقد والتغييرات فـ[سجل المراجعة الثانية](../REVISION_V2.md).

## تجربة المشهد الورقي

`CraftStudy` تجربة جديدة من تسع ثواني بعد رفض الإخراج السابق. فيها مشهد واحد فوق مكتب: نفس المعدّل كيحجب أسماء الشعب، ومنين كتترفع الورقة كيبان الاختلاف، ثم كتبقى الخلاصة فالمشهد نفسه. المصادر وخطوات التفكير فـ[سجل البحث](../research/CRAFT_RELEARNING_20261112.md).

```powershell
python scripts/prepare-craft.py
npm run check
node --max-old-space-size=512 scripts/craft-render.mjs bundle
node --max-old-space-size=512 scripts/craft-render.mjs video
python scripts/verify-craft.py
```

تجهيز الحزمة والتصدير مفصولين باش ذاكرة التجهيز تتحرر قبل تشغيل المتصفح. الرسوم أصلية ومتولدة من الكود، والصوت مؤثر ورقي اصطناعي محلي، بلا تعليق صوتي. `out/craft-study.mp4` هو مسار التصدير، و`out/craft-qa/` فيه صور القياس والتحقق. هادي تجربة أسلوب، وما كتولي إعلان مصادق عليه غير بنجاح الفحوص التقنية.

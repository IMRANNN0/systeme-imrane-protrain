## Feedback processing

For each owner comment, preserve the words and identify target version/timecode. Classify it as factual/technical error, wording change, creative preference or performance hypothesis. Correct the authorized item without changing unrelated approved copy or brand. If a new instruction supersedes an old one, link both and date the change.

Do not translate an isolated preference into a universal rule for every client. No compulsory animation quota, music track, transition package or exact CTA percentage. No performance claim without actual campaign evidence.

## Review and approval records

Record storyboard approval against its revision and script hash; record creative/voice/owner feedback against the artifact hash. Keep technical inspection separate from subjective review. A model cannot grant owner approval, and a script that writes JSON cannot truthfully claim someone listened.

Missing reply, elapsed time, a preselected choice or a file marked final is not consent. Once authorization is concrete and within scope, proceed without repeatedly requesting the same approval. Additional paid scope, changed marketing message or publication requires its own applicable authorization.
